# Coquette Furniture 🎀

*A Sugarplum Studios mod for Minecraft Java 1.20.1, 1.21.1, 26.2 and 26.3, on Forge, Fabric and NeoForge*

Dream bedrooms and pastel home decor. **37 pieces of furniture in six colourways**
(Baby Pink, White, Cream, Lavender, Mint, Baby Blue), **4 potted plants** and
**13 decorations**: 239 blocks in all. Each one is a detailed model with
cabriole legs, gold knobs, satin bows, lace trims, tufted cushions and hearts.
Most of them do something too: you can sit, sleep, store, cook, bathe, wash
up, light candles, play music or get pampered.

---

## Installing

| Minecraft | Loaders | Java | Also install |
|---|---|---|---|
| 1.20.1 | Forge (47+), Fabric | 17+ | Fabric API on Fabric |
| 1.21.1 | NeoForge (21.1+), Fabric | 21+ | Fabric API on Fabric |
| 26.2 | NeoForge, Fabric | 25+ | Fabric API on Fabric |
| 26.3 | NeoForge, Fabric | 25+ | Fabric API on Fabric |

Put the jar for your loader and version (`coquettefurniture-<loader>-<minecraft>-1.0.0.jar`) in your `mods` folder, on the
server and on every client. The release jars are in `release/1.0.0/`.

## Special features

* **Interior Designer Mode.** Right-click the **Interior Design Catalog** (every player gets one
  on first join; craft one from a book and pink dye) or press **K**. Browse by room or by set,
  search by name, filter by colour. Selecting a piece shows a big 3D preview, what it does,
  which sets it belongs to and its live crafting recipe. In creative, *Take one*, *Take a stack*
  and *Take the whole set* deliver pieces to your inventory.
* **Furniture Sets.** Princess Bedroom, Strawberry Cottage, Lavender Dreams, Angelcore Room and
  Pastel Kitchen. Shown in the catalog and in item tooltips.
* **Decoration system.** Lamps, tea sets, jewelry boxes, soap dispensers, flower pots, pillows
  and all decorations **sink** in 2 px steps onto whatever they're placed on: bedside table
  (2 px), vanity (4 px), dining/outdoor table (2 px), coffee table, sofa, armchair, bench, bed
  and vanilla bottom slabs (8 px). Full-height tops (dressers, counters, bookshelves, cabinets)
  need no sinking. If the surface is removed, the decoration settles back to block height.
* **Recolouring.** Right-click any placed piece with **pink / white / yellow / purple / lime /
  light blue dye** to repaint it Baby Pink / White / Cream / Lavender / Mint / Baby Blue. Both
  halves of two-block pieces change together and storage keeps its contents. In the crafting
  grid, any colour of a piece plus a dye also gives that colour.
* Every furniture recipe is unlocked in the recipe book on join.

### Good to know
* **Rugs and picnic blankets behave like vanilla carpet**: anything placed on top goes in the
  block above and floats. Lay rugs in open floor space, and set baskets and gifts on the ground
  beside the blanket.
* A decoration that has sunk 8 px onto a low surface (coffee table, sofa seat, bed) sits mostly
  inside the block below it. Aim at its **upper half** (or stand close) to click or break it.
* Two-block pieces need the second space free: beds and bathtubs extend away from you, tall
  pieces upward. The canopy, the vanity mirror and chair crowns are taller than one block, so
  leave headroom above them.

## Configuration

`config/coquettefurniture-common.toml`: seating, dye recolouring, endless sink water, vanity
effect & cooldown, bath regeneration, tea pouring, jewelry box melodies, bookshelf enchanting
power, catalog delivery outside creative (off by default), catalog on first join, recipe unlocking.

`config/coquettefurniture-client.toml`: feature tooltips, set tooltips, birdhouse chirps,
spinning display cabinet items.

## In-game testing guide

Start with `cd 1.20.1 && ./gradlew :forge:runClient` (or `:fabric:runClient`; any other workspace works the same way), then create a **Creative** world (flat is easiest) with cheats on.
Each step lists what you should see.

### 1. Catalog & sets
1. On joining you have an **Interior Design Catalog**. Right-click it (or press **K**).
   → A pink, lace-trimmed catalog with room tabs, a search box and seven colour swatches.
2. Click **Bedroom**, then the **Lavender** swatch. → Only lavender bedroom pieces.
3. Type `sofa` in the search box. → Only sofas.
4. Click a piece. → Big 3D preview, room, recipe grid (ingredients cycle), feature list, sets.
5. Click **Take one** / **Take a stack**. → Item(s) delivered, pink "Delivered" message.
6. Open **Themed Sets**, pick *Princess Bedroom*, click **Take the whole set**. → 17 pieces delivered.
7. Switch to survival (`/gamemode survival`) and reopen. → Take buttons hidden; "Craft it at a crafting table" shown.
8. Hover any piece in the inventory. → Tooltip lists features, "Right-click with a dye to recolour" and its sets.

### 2. Bedroom
1. Place a **Canopy Bed** (needs 2 blocks of floor, and headroom for the canopy).
   Right-click at night. → You sleep; the night skips; your spawn is set.
2. Place **Decorative Pillows** on the bed's head. → The pillow pile sits on the mattress.
   Place two more on the pile. → 3 pillows (heart cushion, then bolster). Break it. → Drops 3.
3. Put a **Bedside Table** next to the bed; place a **Night Lamp** on top. → The lamp stands on
   the table top (no gap). Right-click the lamp. → Light toggles.
4. Right-click the Bedside Table, **Dresser**, **Wardrobe**. → 9 / 27 / 54-slot screens; the drawer
   slides out / the doors swing open while the screen is open; they close afterwards.
5. **Jewelry Box** on the dresser: open it. → 5-slot screen, lid open, chimes play a melody with note particles.
6. **Vanity Table**: right-click. → Compliment, hearts and sparkles, Regeneration. Again right away:
   "makeup is still perfect" (cooldown). Sneak + right-click: drawer screen.
7. **Standing Mirror**: right-click. → Compliment. Break the top half in survival. → One mirror drops.

### 3. Living room
1. Place three **Sofas** in a row facing the same way. → One long sofa with arms only at the ends;
   break the middle one and the ends become single sofas again.
2. Right-click a sofa or **Armchair** with an empty hand. → You sit facing forward; sneak to stand.
   Someone else clicking the same seat sees "Someone is already sitting there".
3. **Coffee Table**: place a **Tea Set**, **Pastel Candles** or **Rose Vase** on it. → They stand on the low top.
4. **Bookshelf**: surround an enchanting table with 15. → Level 30 enchantments.
5. **Display Cabinet**: right-click the lower left of the glass with a diamond, the upper right with a plushie.
   → The items appear on the matching shelves and slowly spin. Empty hand takes them back.
6. Lay a 3×3 of **Rugs**. → One rug with a single fringed border.
7. **Curtains** on a wall over a window: right-click. → Tied open with bows / closed. You can walk through them.

### 4. Kitchen
1. **Kitchen Sink**: right-click with an empty bucket, then a glass bottle. → Water bucket, water
   bottle. Empty hand: water runs with splashes; again to stop.
2. **Stove**: right-click, cook raw beef with coal. → Smoker screen, cooks in 5 seconds; burners and
   oven glow, smoke rises, nearby blocks are lit.
3. **Refrigerator**: open. → 36 slots, both doors open on cake, milk and strawberries.
4. **Dining Tables** in a 2×2. → One big table with four legs at the outer corners. Chairs around it; sit.
5. **Tea Set**: right-click with a glass bottle. → *Cup of Strawberry Tea*. Drink it. → Regeneration, bottle returned.

### 5. Bathroom
1. **Bathtub**: right-click with a water bucket. → Both halves fill with bubbly water (and a duck).
   Sit in it. → "A relaxing bubble bath", bubbles, Regeneration while seated. Empty bucket scoops the water out.
2. **Bathroom Sink**: same as the kitchen sink.
3. **Wall Mirror**, **Bathroom Cabinet** and **Towel Rack**: click the side of a wall to hang them.
   → They sit flat against the wall. Open the cabinet: the mirrored door swings open.
4. **Soap Dispenser** on a counter. Right-click. → Bubbles and "Squeaky clean!".

### 6. Garden
1. **Picket Fence**: place a line; attach a lead. → Connects like a fence, holds the lead, joins oak fences.
2. **Garden Bench** ×2 side by side; **Swing Seat**; sit on both.
3. **Birdhouse**: right-click. → Chirp and music notes; it chirps by itself now and then in daytime.
4. **Outdoor Table** with a **Flower Pot** on it; **Picnic Blanket** 2×2 with a **Strawberry Basket** on it.

### 7. Customisation & survival
1. Hold **purple dye** and right-click a pink wardrobe full of items. → Both halves turn lavender; contents kept; one dye used.
2. Craft a Mint Sofa: wool, wool, planks and **lime dye** (see the catalog recipe). Then put the mint sofa and any dye
   in the grid. → That colour of sofa.
3. Break pieces in survival. → Each drops itself (two-block pieces drop once). Storage spills its contents.
4. Place furniture under water. → It's waterlogged.

### 8. Automated checks
`cd 1.20.1 && ./gradlew :forge:runGameTestServer`: 14 tests covering recipes and loot for all 239 blocks, sitting, sofa/table/rug
joining, decoration sinking, pillows, sinks, bathtubs, recolouring with contents, storage sizes and open
models, beds, stove cooking, lamps/candles/curtains and the display cabinet.

## For developers

The repository holds one MultiLoader workspace per Minecraft version, laid out like the other Sugarplum Studios mods:
`1.20.1/` (common, fabric, forge), and `1.21.1/`, `26.2/` and `26.3/` (common, fabric, neoforge). `common` holds all
gameplay, rendering and data and compiles against vanilla Minecraft only; the loader modules are thin layers
(registration, networking, events, key binding, renderers, render layers) behind `platform.IPlatform`.

| Command | What it does |
|---|---|
| `cd 1.20.1 && ./gradlew build` | Builds `forge/build/libs` and `fabric/build/libs` (Java 17) |
| `cd 1.21.1 && ./gradlew build` | Builds `neoforge/build/libs` and `fabric/build/libs` (Java 21) |
| `cd 26.2 && ./gradlew build` | Same for 26.2 (Java 25); `26.3` likewise |
| `./gradlew :fabric:runClient` | A development client (also `:forge:` / `:neoforge:`) |
| `./gradlew :forge:runGameTestServer` | 1.20.1: the 14 GameTests, headless |
| `./gradlew :forge:runClient -Pshowcase` | Builds a furnished world, screenshots every room and the catalog into `run/screenshots/`, then quits (every loader) |
| `./gradlew :forge:runClient -Pmarketing` | 1.20.1: the 1920×1080 listing captures (see `marketing/README.md`) |
| `tools/devtest.sh <version> <loader>` | Load test: starts the dev server and the showcase client, then prints any errors in their logs |
| `python tools/generate_assets.py` | Regenerates every texture, model, blockstate, item model, loot table, recipe, tag and the language file into `1.20.1/common/src/main/resources`, then checks every reference |
| `python tools/port_data.py <version>` | Derives the `1.21.1`, `26.2` or `26.3` resources from the 1.20.1 ones (1.21 folder names, recipe and loot formats, item model definitions) |
| `python tools/preview_models.py out.png <model>...` | Renders models to an isometric preview sheet without starting Minecraft |
| `python tools/make_logo.py` | Rebuilds the mod-list logo from real furniture renders |

The Python tools need Python 3.8+ and no extra packages. Config files are read by a small TOML reader in `common`
(`config/TomlConfig.java`), so `coquettefurniture-common.toml` and `coquettefurniture-client.toml` have the same layout
and keys on every loader and version.
